# pokégit

a chrome extension that analyzes public github profiles. a fun < 1 hour hack, not meant to be serious!

## How to use it

1. `chrome://extensions` → Developer mode → **Load unpacked** → this folder  
2. open a GitHub **profile** or **repository**  
3. click the pokégit pokéball in the corner
